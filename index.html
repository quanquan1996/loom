Claude Code, Codex and Kiro run on your server; your phone, tablet and laptop all join the same session. Close the tab and it keeps working. Restart the server and it still doesn't stop.

Features

智能体想要的一切，都织在一起。Everything an agent needs, woven together.

聊天、终端、画布、定时任务、你自己的电脑、一个已登录的浏览器 —— 一个页面，所有设备。Chat, terminals, a canvas, schedules, your own computers, a logged‑in browser. One page, every device.

💬

会话活在服务器上Sessions live on the server

在电脑上开始一个任务，在地铁上用手机看它完成。断线重连只补发错过的部分；智能体干活时发的消息会直接并入当前回合，不用等。Start a turn on the laptop, watch it finish on the phone. A reconnecting tab replays only what it missed, and a message sent mid‑turn joins the running turn.

GenServer / sessionPhoenix Channels/compact/reloadattachments
⌨️

真正的终端Real terminals

PTY Shell 和聊天并排，可开多个。关掉标签页也不会断，两台设备可以共用一个 Shell；tmux / nvim 的复制能直达浏览器剪贴板。PTY shells beside the chat. They outlive the tab, two devices can share one, and OSC 52 copies from tmux/nvim reach your clipboard.

🎨

画布Canvas

智能体写进 output/ 的网页、图表、仪表盘会马上出现在右侧，运行在沙箱里。图片、音视频、Markdown、CSV 都有内置预览。Pages, charts and dashboards an agent writes to output/ appear beside the chat, sandboxed. Built‑in viewers for media, Markdown and CSV.

🎞

一句话出幻灯片Slides in one ask

reveal.js + 代码高亮 + KaTeX 公式，资源由 Loom 自己提供，离线也能放映，一键导出 PDF。reveal.js with highlighting and KaTeX, served by Loom itself so it works offline, with a one‑click PDF.

⏰

用大白话定时Schedules in plain words

"每个工作日早上 10 点帮我查一下……" —— 智能体会自己建定时任务，按你的本地时间触发，在任务页里统一管理。"Every weekday at 10:00, check…" — the agent creates the job itself, on your wall clock, listed on the Tasks page.

🖥

loom‑node：操作你自己的电脑loom‑node: your own machines

一行命令装到 Mac、Windows、Linux 或 WSL 上，任意会话里的智能体都能以你的身份在那台机器上执行命令、读写文件。只往外连，不开端口，躲在家用路由器后面也能用。One line installs it on a Mac, Windows PC, Linux box or WSL; agents in any session can then run commands and move files there as you. Outbound only, so it works behind NAT.

已登录的浏览器A logged‑in browser

服务器上常驻一个 Chromium，智能体通过 CDP 操作它，看到的页面和你自己登录后的桌面 Chrome 一样。遇到验证码时，你可以用手机形状的窗口接管一下，处理完再交回给它。A Chromium that stays up on the host, driven over CDP, so agents see the pages a logged‑in desktop Chrome would. Hit a captcha? Take it over in a phone‑shaped window, then hand it back.

手机优先的 PWAPhone‑first PWA

可以装到主屏幕，回合结束时推送到锁屏，多台设备同步未读状态。网络差时没发出去的消息会标红色"!"，点一下就能重发，不会重复发送。Installable, with lock‑screen pushes when a turn ends, unread state synced across devices, and a red "!" to resend a message a weak network dropped, without sending it twice.

📁

项目与记忆Projects & memory

把会话归入项目，同一项目的会话共用工作区和记忆；可以置顶、移动、折叠。新会话会自动归档到它所属的项目。Group sessions into projects that share a workspace and memory. Pin, move, fold; a new session files itself into the right project.

⌘

Vim 键位Vim keys

i 输入，j/k 滚动，空格作为 Leader 键切换面板，? 查看全部快捷键。还能调字号、深浅色主题和思考强度。i to type, j/k to scroll, Space as leader for panes, ? for the list. Plus text size, themes and a thinking slider.

Restart‑proof

服务器在重启，
智能体照常干活。Loom restarts.
The agent never notices.

Loom 会先放开 CLI 的 stdio，让 Claude Code / Kiro 独立跑完这一回合；新版本起来后从文件恢复状态，按原来的 PID 重新接管。所以在一次对话里修改 Loom、部署 Loom，都很安全。Loom lets go of the CLI's stdio, the Claude Code / Kiro process runs on alone, and the new release restores state from disk and adopts it, same PID. Editing and deploying Loom from inside a Loom turn is safe.

Sleep

它会睡觉，
睡醒后更懂你。It sleeps,
and wakes up knowing you better.

灵感来自大脑睡眠时的记忆巩固。每天凌晨，Loom 会把白天的对话重放一遍：你纠正过的、说过"记住这个"的，权重最高；然后整理项目记忆，写一份晨报给你。Inspired by how brains consolidate memory in sleep. Each night Loom replays the day's sessions, weighs your corrections and "remember this" highest, tidies the project's memory, and leaves you a morning report.

Architecture

一个会话，一个 GenServer。
简单，所以可靠。One session, one GenServer.
Simple, so it holds.

Loom 自己不调用任何模型 API，真正干活的是 claude / codex / kiro CLI。Loom 负责让它们一直在线、可以从任何地方接入、状态都落在磁盘上。Loom makes no model requests of its own; the claude / codex / kiro CLIs do the work. Loom keeps them alive, reachable from anywhere, and on disk.

Backend

Elixir / Phoenix

OTP 监督树；每个会话、每个 PTY 各对应一个进程，通过 Channels 推流。OTP supervision; a process per session and per PTY, streamed over Channels.

Frontend

React + Vite

xterm.js、沙箱画布、PWA、Web Push，并针对手机做了专门打磨。xterm.js, a sandboxed canvas, PWA, Web Push, tuned for phones.

Agents

claude · codex · kiro

stream-json、app-server、ACP 三种协议，都是实测后接入的。stream‑json, app‑server and ACP — protocols as measured.

Devices

loom‑node (Go)

单个二进制文件，原生支持 macOS / Linux / Windows，通过 Phoenix socket 向外连接。One binary, native on macOS / Linux / Windows, dialing out over a Phoenix socket.
