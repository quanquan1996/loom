Loom is a web page: Claude Code runs on your own server, your phone adds it to the home screen as an app, and every device you have plugs in.

客户端超轻A featherweight client

打开一次只下载约 270 KB（压缩后）。终端、远程桌面这些重的部分用到才加载，弱网下也能很快打开、点一下就有反应。About 270 KB (gzipped) on first open. The heavy parts, like the terminal and remote desktop, load only when used, so it opens fast and answers taps even on a weak network.

服务端高性能A high‑performance server

服务端用 Elixir / Phoenix，跑在专为电信系统打造的 BEAM 虚拟机上：每个会话是一个独立的轻量进程，几十个会话、员工、设备同时跑互不拖累，消息通过 WebSocket 实时推到每个打开的页面。Elixir / Phoenix on the BEAM, the VM built for telecom switches: each session is its own lightweight process, so dozens of chats, employees and devices run side by side without slowing each other, and every update streams live over WebSocket to every open page.

Always on

你放下手机，它还在干活。Put the phone down. It keeps working.

重启不断线Restart‑proof

关掉浏览器它还在跑；服务器重启时，正在进行的回合照常跑完，新版本起来后接回来。所以在 Loom 里改 Loom、部署 Loom 都很安全。Close the browser, it runs on; restart the server and the turn in flight finishes and is taken back. Changing and shipping Loom from inside Loom is safe.

睡一觉，更懂你Sleeps on it

每天凌晨回看白天的对话，整理记忆、提议新 skill，写一份晨报；只提议不越权，一键撤销。Each night it replays the day, tidies memory, proposes skills and leaves a report; it only proposes, and every change can be undone.

招几个 AI 员工Hire AI employees

给它 KPI 和预算，靠心跳定时醒来推进工作，每周交周报；说过一次的规矩所有员工都知道，也能安排在你的某台电脑上干活。Give one KPIs and a budget; a heartbeat wakes it to push them on, with a weekly report. Tell one a rule and all of them know; seat one on a computer of yours.

No lock‑in

不绑任何厂家。
机器、数据、模型都是你的。Tied to no vendor.
Your machines, your data, your models.

Loom 不调任何模型 API，也不依赖任何云服务：哪个 agent 命令行好用就用哪个，随时换；任何一台 Linux 都能当服务器；推送走浏览器标准的 Web Push。Loom calls no model API and depends on no cloud service: use whichever agent CLI is best and switch any time; any Linux box is a server; push is plain browser Web Push.
